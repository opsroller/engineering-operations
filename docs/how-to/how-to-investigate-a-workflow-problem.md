How-to guide: for an engineering operations agent deciding whether to send another agent after a workflow problem.

# How to investigate a workflow problem carefully

This guide shows you how to get an answer the records do not give,
for the least cost and with no side effects.

1. Write the question in one sentence. If you cannot, you are not
   ready to investigate.
2. Try to answer it yourself from the records first. Most questions
   end here.
3. Run the `investigations` checklist. If any box is empty, record the
   finding as it stands and stop.
4. Write the brief from the skill's template: the question, the
   records to read and nothing else, the read-only rule, a budget and a
   stop rule.
5. Send one investigator, on a lighter model if the job is counting or
   collecting. Send more only for independent questions, at most three.
6. Check the answer against its evidence links. An answer without links
   is unverified.
7. Add the answer, its confidence and its cost to the finding, then
   send the finding to its owner.
