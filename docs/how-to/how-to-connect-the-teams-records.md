How-to guide: for an engineering operations agent starting in a project that does not yet say where its records live.

# How to connect the team's records

This guide shows you how to find the records every review reads and get
their locations into the project's profile, once.

1. Read the project's `CLAUDE.md` and profile. If they already name the
   records and an operations reference page, stop here.
2. Find each record in the `operating-data` table: workflow run
   results, the gap log, CI history, review verdicts, work records,
   usage and spend, blocker notes. Note how each is read (a file path,
   a service, a page) and whether you can read it.
3. Pick the path for the operations reference (measures, findings,
   improvements, review log, budget) under the project's reference docs.
4. Send the list to whoever maintains the project profile (usually the
   coordinator) as one proposal. Do not edit the profile yourself if
   another role owns it.
5. For any record you cannot read, record it as a data gap and name
   the one action that would open it (for example, access to a usage
   page). Say it once.
6. Write the first measure definitions with `operating-data`, then run
   [an operations review](how-to-run-an-operations-review.md) to set the
   baselines.
