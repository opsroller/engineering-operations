# Sources

Reference: the research behind this plugin, for anyone checking where its methods come from.

| Source | Informed |
|---|---|

| [UK Government DDaT framework: performance analyst](https://ddat-capability-framework.service.gov.uk/role/performance-analyst) | Performance analysis as a role, levels from associate to head (explanation) |
| [FinOps Foundation: FinOps Principles](https://www.finops.org/framework/principles/) | Collaboration, ownership of usage, timely and accurate data, business value drives decisions (`cost-and-usage`) |
| [FinOps Foundation: FinOps Framework](https://www.finops.org/framework/) | Inform, optimize, operate phases; allocation, anomaly management, forecasting, budgeting, unit economics, usage vs rate optimisation (`cost-and-usage`) |

| [Google SRE Workbook: Eliminating Toil](https://sre.google/workbook/eliminating-toil/) | Definition of toil, measuring it in objective units, cost-benefit before automating (`waste-hunting`) |
| [Google SRE Book: Postmortem Culture](https://sre.google/sre-book/postmortem-culture/) | Blameless findings about systems, not people (`waste-hunting`, agent) |
| [Lean software development (Wikipedia, after Poppendieck)](https://en.wikipedia.org/wiki/Lean_software_development) | The seven wastes of software development: partly done work, extra process and features, relearning, hand-offs, task switching, delays, defects (`waste-hunting`) |
| [Lean Enterprise Institute: Value-stream mapping](https://www.lean.org/lexicon-terms/value-stream-mapping/) | Following one kind of work across every step and its waits (`waste-hunting`) |
| [ASQ: PDCA cycle](https://asq.org/quality-resources/pdca-cycle) | Plan, do, check, act; small changes tested before they are standardised (`improvement-cycle`) |
| [ASQ: Continuous improvement](https://asq.org/quality-resources/continuous-improvement) | Incremental, measured improvement as an ongoing practice (`improvement-cycle`, explanation) |
| [Diataxis](https://diataxis.fr/) and the project's Diataxis guide | Docs layout of this plugin and the docs steps in every workflow |
